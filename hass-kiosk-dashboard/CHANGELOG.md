# Changelog

## 1.1.0

- Added Home Assistant add-on packaging for amd64 and aarch64.
- Added ingress-only access and relative asset/API routing.
- Added automatic Supervisor API authentication without a user PAT.
- Added Home Assistant username-based settings permissions.
- Added persistent shared settings in the add-on data directory.
- Added a direct dashboard link and expired-session handling.
- Retained standalone mode for local development.

## 1.0.0

- Added the Swedish tablet dashboard with calendars, weather, and lighting controls.
- Added centrally stored settings and a standalone Home Assistant API proxy.
