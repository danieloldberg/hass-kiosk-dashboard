# hass-kiosk-dashboard

Svensk dashboard för en äldre Android-surfplatta med kalender, väder och belysning.

Öppnas genom Home Assistant ingress. Gemensamma inställningar hanteras från datorn och hämtas automatiskt av surfplattan. Ingen PAT behövs.

Ange ditt Home Assistant-användarnamn i `settings_users` under tilläggets konfiguration. Starta sedan tillägget, öppna webbgränssnittet och välj enheter via kugghjulet.

På surfplattan öppnar du tillägget genom Home Assistant en gång. Tryck sedan **Öppna utan ram ↗** för en fristående dashboardvy.

Se fliken **Dokumentation** för fullständiga instruktioner och felsökning.
